# AmneziaWG Management Script

Bash-скрипт для установки и управления AmneziaWG на bare-metal серверах через [bivlked/amneziawg-installer](https://github.com/bivlked/amneziawg-installer).

## Использование

### Как меню:
```bash
sudo ./awg.sh
```

### Как библиотека (для ботов и скриптов):
```bash
source ./awg.sh
awg_list_clients_human
awg_add_client myname
awg_show_client myname
```

## Функции

- **Установка** — автоматическая установка AmneziaWG с проверкой статуса
- **Список клиентов** — список активных клиентов с их параметрами
- **Добавление клиента** — создание нового клиента с опциональным сроком действия
- **Удаление клиента** — удаление клиента из конфигурации
- **QR-код** — вывод QR-кода конфига в терминал (требует `qrencode`)
- **Статистика** — статистика использования в JSON формате
- **Блокировка** — flock-защита от конкурентных операций

## Требования

- Ubuntu 24.04+ (или другой дистрибутив, поддерживаемый bivlked/amneziawg-installer)
- Права root
- wget (для скачивания установщика)
- qrencode (опционально, для QR-кодов в терминале)

## Примеры

### Добавить клиента
```bash
sudo ./awg.sh
# Выбрать пункт 2, ввести имя клиента
```

### Показать конфиг с QR-кодом
```bash
sudo ./awg.sh
# Выбрать пункт 1 для просмотра списка
# Выбрать пункт 2, добавить клиента
# QR-код отобразится автоматически
```

### Из скрипта (библиотека)
```bash
#!/bin/bash
source /path/to/awg.sh

# Добавить клиента с истечением через 30 дней
awg_add_client "user1" "2026-09-24"

# Показать конфиг
awg_show_client "user1"

# Список клиентов
awg_list_clients_human
```
